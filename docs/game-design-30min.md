# my-sample-rpg 설계안 — 플레이타임 30분 목표

이 문서는 플레이타임을 30분으로 늘리는 설계안과 진행 상황을 기록한다.
작업할 때마다 갱신한다. 맨 아래 "변경 기록"에 날짜와 무엇을 했는지 남긴다.

## 원칙

- **디자인 통일:** 플레이어, NPC, 몬스터, 무기, 이펙트, 아이콘, 타일을 한 그림체(LPC 계열)로 맞춘다.
  새 에셋은 LPC 비율·팔레트·외곽선에 맞는지 먼저 확인한다.
- **직업 없음:** 시작 직업이 없다. 장착한 무기가 공격 방식을 정한다.
  - 검: 근접 베기
  - 지팡이: 대상을 조준하는 에너지볼트
  - 활: 대상을 조준하는 화살
- **무기별 스킬:** 무기 계열 스킬은 그 무기를 들어야 쓸 수 있다. 마법 스킬은 지팡이, 활 스킬은 활이 필요하다.
- **배포 품질:** 모든 변경은 렌더 이미지와 실제 게임 화면으로 확인한다. 충돌과 도달 가능 여부도 검사한다.

## 현재 상태 (2026-10-04 분석)

| 구분 | 처음 하는 플레이어 (보통) | 범위 |
|---|---|---|
| 메인 퀘스트 (q001~q008, 엔딩) | 약 12분 | 5~23분 |
| 사이드 포함 전부 (q009 광산, q010 딴따라마을) | 약 17분 | 8~33분 |

주요 수치 (근거 파일):

- **이동:** 8타일/초 (`characterState.ts`, `playerStatEffects.ts`)
- **몬스터 체력:** `(10 + 2×레벨) × 배수`. 동굴에서는 체력·피해·크기가 2배 (`monsterCombat.ts`)
- **근접 피해:** 힘 5 + 기본 무기 2 = 7. 공격 동작 320ms, 쿨다운 300ms
- **경험치:** 레벨업 필요량 `140 + (레벨−1)×30`. 메인 퀘스트 경험치 합계 2,340은 레벨 1→10에 필요한 양과 같다.
- **리스폰:** 모든 몬스터와 보스가 8초 뒤 다시 생긴다.
- **시작 자원:** 골드 1000, 체력·마나 포션 각 30개

페이싱 문제:

1. 퀘스트 대사가 말풍선 하나로 3.6초만 보이고 사라져 읽을 수 없다.
2. 사냥터에 몬스터가 4마리뿐이고, 동굴에는 보스만 있다. 보스도 8초 뒤 다시 생겨 엔딩 대사와 맞지 않는다.
3. 시작 골드와 포션이 많아 경제 압박이 없다.
4. 마을↔동굴 왕복이 세 번 반복된다. q005·q007은 채우기용 퀘스트다.
5. 나중에 열리는 광산 몬스터가 앞서 나오는 동굴 보스보다 약하다.
6. 레벨 10에서 "전직 가능"이라고 안내하지만 전직 기능이 없다.

### 맵 판정 (2026-10-04)

결론: 전면 재설계는 하지 않는다. 사냥터만 새로 만들고 나머지는 개선한다.
LPC 캐릭터(약 30×53px)와 맵의 비율은 맞는다(문 32×56px). 문제는 그림체 일부와 게임플레이 밀도·동선이다.

| 맵 | 판정 | 핵심 이유 |
|---|---|---|
| 마을 | 개선 | 스타일 변환 데모가 오브젝트 주석에 묶여 있다. 건물·잔디가 LPC가 아니고, 빈 광장이 넓다. |
| 사냥터 | **재설계** | 몬스터 4마리, 사냥 구역이 없다. 동굴 입구 랜드마크가 없다. 테스트 영향이 작다. |
| 딴따라마을 | 개선 | 마을 시청과 같은 건물을 복제했고, 같은 집을 반복한다. 거리와 소품 뼈대는 좋다. |
| 동굴 | 개선 | 이미 LPC 그림체다. 일반 몬스터 통로를 쓰지 않고 있다. 문 앞에 반투명 네모 덮개가 보인다. |
| 수정 광산 | 개선 | 레이아웃은 좋다. 난이도, 보스, 광석 목표를 데이터로 고친다. |

새 월드 연결 (노드 유지, 지름길 추가):

```
딴따라마을 ─ 마을 ─(동문)─ 사냥터 ─ 북동 낭떠러지 동굴 입구 ─ 동굴 ─ 수정 광산
                              ├ 중앙 야영지 (상인, 귀환 표지석 = 지름길)
                              └ 남동 무너진 광산 입구 (q009 이후 개방, 광산 귀환문과 연결)
```
