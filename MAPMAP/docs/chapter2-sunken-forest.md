상태: **메인 이야기 완료** (2026-10-04~05). 곁가지(c2-s1~s6)·장비 등급·2장 곡은 남음. 윗물길 + c2-01(q016), 갈대골 + c2-02(q017), 잠긴숲 + c2-03(q018), 독안개 + c2-04(q019·q020),

상위 문서: `docs/game-roadmap-10h.md` (10시간 로드맵), 1장 기록: `docs/game-design-30min.md`.

## 목표

- 1장(약 25분)에 이어지는 **약 70~80분** 분량의 장. 메인 약 45분, 곁가지 약 30분.
- 1장에서 풀리지 않은 질문 — "몬스터를 사납게 만든 어두운 기운은 어디서 왔나" — 에 답한다.
- 새 지역 4곳, 새 몬스터 5종(+보스 2), 장비 한 등급, 지역 고유 장치 2가지.

## 이야기

### 연결고리 (1장에 이미 있는 것)

- q012 "수문지기의 안부": 이멜이 **"물이 줄고 있었구나…"** — 상류 물이 줄고 있다.
- q013: 동굴에서 날아온 **독 포자**가 정원을 시들게 했다.
- q006·q008: 마법사는 동굴의 기운이 "더 깊은 곳에서 화가 난 것처럼 움직인다"고 했다. 꿀꿀이-보스는 원인이 아니라 **기운에 홀린 쪽**이었다.

### 줄거리

1. **물이 사라지는 수로** — 물레골 수문지기 이멜이 플레이어를 부른다. 개울 상류의 물이 땅속으로 빨려 들어가고 있다. 수로를 거슬러 올라가면 숲 하나가 통째로 늪에 잠겨 있다.
2. **늪지 마을 갈대골** — 늪 위 나무다리로 이어진 작은 마을. 마을 사람들은 "숲이 가라앉기 시작한 건 석 달 전, 유적의 종이 처음 울린 밤부터"라고 말한다. 여기가 2장 거점이다.
3. **잠긴숲** — 물에 잠긴 고목과 독안개. 사냥꾼이 사라지고, 물에 빠져 죽은 자들이 걸어 다닌다.
4. **물밑 신전 외곽** — 무너진 돌기둥과 비석. 비석의 고대 문자는 "봉인 셋이 물을 붙든다"고 적는다. 물이 빠지는 건 **봉인이 하나씩 깨지고 있기 때문**이다.
5. **물밑 신전** — 두 층. 1층은 물이 찬 회랑, 2층은 봉인의 방. 봉인을 깨던 존재는 **늪의 사제**(고대 신전을 지키던 사제가 기운에 삼켜진 것). 사제를 쓰러뜨리면 물이 다시 흐르기 시작한다.
6. **끝과 다음 장 떡밥** — 사제가 쓰러지며 "우리는 막고 있었을 뿐… 진짜 깨어나는 것은 **북쪽**에 있다"고 말한다. 3장으로 넘어가는 고리.

## 지역과 연결

```
물레골 ─(수문 옆 새 출구)─ [새] 윗물길 ─ 갈대골(거점) ─ 잠긴숲 ─ 물밑 신전 외곽 ─ 물밑 신전 1층 ─ 2층(보스)
                                                   └─ 나룻배 지름길(곁가지 후 개방) ─ 신전 외곽 야영지
```

- 물레골에는 출구가 `north_arch_gate`(느티골행) 하나뿐이다. 이멜이 지키는 **개울 상류 수문 옆에 새 출구**를 만들어 2장 입구로 쓴다 — 이야기(물을 거슬러 올라간다)와 동선이 같다. q014 완료 전에는 수문이 닫혀 있게 퀘스트 속성(`quest.requiresCompleted`)으로 막는다.
- 각 맵은 1장과 같이 **생성 스크립트**(`scripts/generate-<맵>.py`)로 만든다 — 다시 생성해도 결과가 같고, 고칠 때 스크립트를 고친다.

| 맵 | 크기(안) | 성격 | 주 타일 |
|---|---|---|---|
| 윗물길 | 40×24 | 짧은 이동 맵. 물이 땅으로 빨려드는 장면을 보여 주는 도입 | Grass_Dark, Water, Mud_Brown, 갈대(cattail) |
| 갈대골 | 44×36 | 거점. 늪 위 나무다리, 집 5~6채, 상점, 귀환 표지석 | Water, Mud, 나무다리, 마을 소품 |
| 잠긴숲 | 60×45 | 메인 사냥터. 물에 잠긴 고목 사이 둑길, 독안개 구역 | Water/Water_Deep, Mud, Grass_Dark, glow_plant |
| 물밑 신전 외곽 | 50×40 | 유적 들판. 돌기둥·비석·석상, 학자 야영지 | Stone_Tan, Mudstone, 유적 소품(pillar, stele_rune, statue_hood, obelisk) |
| 물밑 신전 1층·2층 | 각 40×40 | 던전. 물이 찬 회랑 → 봉인의 방 | Stone_White/Tan, Water, altar, gargoyle, pentagram |

이미 갖고 있는 LPC 타일(`assets/tilesets/lpc/manifest.json`)에 물·깊은 물·진흙·어두운 풀·돌바닥과 유적 소품(제단, 금 기둥, 가고일, 오벨리스크, 룬 비석, 두건 석상, 해골, 거미줄, 빛나는 풀)이 있다. **늪 나무(죽은 나무·물에 잠긴 고목)와 나무다리, 늪지 집**은 없어서 따로 구해야 한다(아래 "필요한 그림").

## 지역 고유 장치

1장과 다르게 "이 지역에서만 하는 것"을 둔다. 많이 넣지 않고 둘만 제대로 만든다.

1. **독안개** — 잠긴숲의 일부 구역에 안개가 깔려 있고, 안에 있으면 체력이 조금씩 줄어든다(중독). 약초꾼 오디의 **해독 향**(소모품)을 쓰면 잠시 막아 준다. 길을 막는 벽이 아니라 "준비하면 지름길"이 되게 배치한다.
2. **봉인 비석** — 신전 외곽과 신전 안의 룬 비석. 다가가 상호작용하면 고대 문자가 빛나고, 셋을 모두 밝혀야 신전 2층 문이 열린다. 각 비석 앞에 수호 몬스터가 있다. (퍼즐은 쉬운 순서 맞추기 수준으로, 막히지 않게 힌트를 대사에 넣는다.)

## 몬스터

레벨대: 1장 끝 Lv14~19 → 2장 **Lv15~25**. 일반 몬스터 체력 배수·보스 배수는 1장 규칙(`monsterTuning.ts`)을 그대로 쓴다.

| 몬스터 (가칭) | 지역 | 행동 | 그림 출처 |
|---|---|---|---|
| 늪개구리 | 상류길·숲 | 뛰어올라 덮친다(짧은 돌진) | LPC 계열 몬스터 팩에서 찾기 |
| 독모기 떼 | 숲 독안개 | 빠르게 날며 중독 | 〃 |
| 물에 빠진 자 | 숲·신전 1층 | 느리지만 단단함 (언데드) | Universal LPC 생성기의 좀비 몸 + 젖은 옷 — 기존 파이프라인으로 합성 |
| 유적 해골병 | 신전 외곽·신전 | 칼·방패 해골 (언데드) | Universal LPC 생성기의 해골 몸 + 무기 — 기존 파이프라인 |
| 이끼 골렘 | 신전 외곽 | 1장 바위돌이의 강화판(색 변형) | 기존 LPC 골렘 시트 색 변형 |
| **늪지기 거대개구리** (중간 보스) | 잠긴숲 깊은 곳 | 혀 당기기, 독 웅덩이 | 늪개구리 확대 + 색 변형 |
| **늪의 사제** (최종 보스) | 신전 2층 | 소환(물에 빠진 자) + 물기둥 | Universal LPC 생성기(로브·두건·지팡이) |

해골병·물에 빠진 자·늪의 사제는 이미 쓰는 Universal LPC 생성기 원본으로 만들 수 있어 그림체가 확실히 맞는다. 개구리·모기는 새 원본이 필요하다.

## 장비 한 등급 (Lv15~25)

- 무기 7종(검·도끼·창·단검·둔기·지팡이·활)마다 2장 등급 하나: 예) 늪철 검, 이끼 지팡이, 갈대 장궁.
- 방어구: 1장의 가죽·사슬·철 다음 등급 한 벌(갑옷·투구·신발) — LPC 생성기에 있는 레이어에서 고른다.
- 판매: 갈대골 대장장이(신규 상점) + 보스 드롭.
- 남는 골드는 장비와 강화에 쓰는 것을 전제로 한다(로드맵의 강화 시스템과 함께).

## 완료 기준 (완성도)

각 맵·퀘스트는 아래를 모두 통과해야 "완료"로 표시한다. 1장 원칙(배포 품질)을 구체화한 것.

맵:
- [ ] 생성 스크립트로 다시 만들 수 있다 (손으로 고친 TMX 없음)
- [ ] 전체 렌더 이미지를 보고 그림체가 섞이지 않았는지 확인 (`notes/tools/render.py`)
- [ ] 충돌·도달 검사: 모든 포탈·NPC·몬스터·상호작용 지점에 걸어서 닿는다 (`notes/tools/collide.py`)
- [ ] 실제 게임 화면 스크린샷으로 확인 (입구, 주요 장소, 보스방) — `notes/shots/` 에 남긴다
- [ ] 반복 타일이 벽지처럼 보이지 않는다: 장식은 뭉쳐 놓고, 그림자로 깊이를 준다

퀘스트:
- [ ] 대사를 처음부터 끝까지 이어 읽어 말투·호칭·인물 설정이 맞는다 (VN 대화창에서 확인)
- [ ] 안내문(guideText)만 보고 목적지를 찾을 수 있다 (지도·추적기)
- [ ] TS·Lua 양쪽 테스트 통과 (Lua parity 포함)
- [ ] 플레이타임 측정 스크립트에 넣어 레벨·시간 곡선 확인

몬스터·장비:
- [ ] LPC 그림체 확인(비율·외곽선·팔레트), 4방향 동작
- [ ] 저작자 표시(CREDITS)와 게임 안 크레딧 화면 갱신
- [ ] 레벨대 전투 측정: 일반 몬스터 3~5대, 보스 전투 1~2분
