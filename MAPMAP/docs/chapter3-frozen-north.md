# 3장 설계 — 얼어붙은 북쪽

상태: **메인·곁가지 구현** (2026-10-06, 실제 게임 화면 플레이 확인 전). 설계 2026-10-05. 상위 문서: `docs/game-roadmap-10h.md`. 앞 장: `docs/chapter2-sunken-forest.md`.

## 목표

- 2장 끝 고리 — 늪의 사제 "진짜 깨어나는 것은 북쪽에", 이멜 "북쪽에서 내려오는 바람이 차갑다" — 를 잇는다.
- 약 60~80분(메인 40~45, 곁가지 20~30). 새 거점 1, 바깥 맵 2, 던전 2층, 중간 보스·최종 보스.
- 새 몬스터 6종(+보스 2), 지역 장치 1(눈보라), 거점 귀환 표지석.
- 레벨대: 2장 끝(메인 Lv36 / 곁가지 포함 Lv45) → 3장 몬스터 **Lv38~46**, 보스 Lv46·49. 3장 끝 플레이어는 메인 Lv47 / 곁가지 포함 Lv58 (`docs/game-balance.md`).

## 이야기

1. **된바람재** — 느티골 북쪽 성문 너머로 오래 닫혀 있던 고갯길이 열린다. 마법사가 전언석으로 부른다:
   "늪의 사제가 막고 있던 것과 같은 기운이 북쪽 산에서 느껴진다."
2. **서리목 마을** — 고갯길 끝 눈 덮인 산골 마을. 석 달 전부터 눈이 그치지 않고, 늑대인간이 마을 가축을 물어 간다.
   촌장 대신 마을을 이끄는 사냥꾼 대장 **하겐**, 약재상 **이르마**(생강차), 대장장이 **볼크**, 마을 아이 **니나**.
3. **거울못** — 호수 한가운데 얼음 속에 옛 종탑이 잠겨 있다. 2장 신전의 종과 같은 문양 — 종은 하나가 아니었다.
4. **트롤 족장**(중간 보스) — 고블린 약탈자와 트롤이 호숫가 서리굴 입구를 차지했다.
5. **서리굴(2층)** — 동굴 깊은 곳 얼음 제단에서 **서리 마녀**가 북쪽의 "잠든 거인"을 깨우려고 종을 울린다.
   그녀는 2장 사제와 달리 스스로 기운을 받아들인 자 — "거인이 깨면 이 땅은 다시 얼음의 시대로 돌아간다."
6. **끝과 4장 고리** — 마녀가 쓰러지며 "거인은 이미 몸을 뒤척였다… 남쪽 불의 산에서 두 번째 종이 울린다." 

## 지역

```
느티골 북쪽 성문 ─ [새] 된바람재(50x28) ─ 서리목 마을(거점, 44x36) ─ 거울못(56x40) ─ 서리굴 1층·2층
```

| 맵 | 성격 | 지형 |
|---|---|---|
| 된바람재 | 눈 쌓인 산길, 고블린 약탈자 매복 | 눈(늪 도구의 눈 바이옴), 얼어붙은 개울, 침엽 고목 |
| 서리목 마을 | 거점: 집 5채, 상점, 귀환 표지석 | 눈, 다진 눈길, 오두막(town 오두막을 눈 지붕으로) |
| 거울못 | 메인 사냥터, **눈보라** 구역, 얼음 속 종탑 | 눈, 얼음(물 대신, 움직이지 않음), 눈보라 |
| 서리굴 1·2층 | 던전, 마녀의 얼음 제단 | 동굴 도구의 얼음 바이옴(푸른 돌바닥·얼음 벽) |

## 지역 장치 — 눈보라

2장 독안개와 같은 틀(지붕 레이어 타일 위에 서 있으면 초당 피해)을 눈보라로 쓴다. 막는 것은 이르마의 **생강차**(소모품,
90초). 독안개와 다른 점: 눈보라 속에서는 **이동이 느려진다**(×0.75) — 피해만이 아니라 길을 고르는 이유가 된다.

## 만드는 순서

1. 눈 바이옴 타일(`append-biome-tiles.py`) — 늪 지형 세트와 동굴 세트를 색만 바꿔 덧붙인다. 생성기 도구가 바이옴을 고른다.
2. 고갯길 + 서리목 + c3-01·02, 귀환 표지석
3. 몬스터 그림(생성기 합성 + 색 변형)
4. 거울못 + 눈보라 + c3-03~05
5. 서리굴 + 두 보스 + c3-06~09
6. 곁가지, 측정, 게임 화면 확인
