# my-sample-rpg 로드맵 — 플레이타임 10시간 이상

상태: 초안 (2026-10-04). 장이 하나 끝날 때마다 측정해서 이 문서를 고친다.

## 목표와 원칙

- **최종 목표: 완성도 높은 10시간 이상의 RPG.** 빨리 만드는 것보다 한 장, 한 맵을 끝까지 다듬는다.
- 1장 원칙을 그대로 지킨다: LPC 그림체 통일, 직업 없이 무기가 싸우는 법을 정함, 무기별 스킬, 모든 변경은 실제 게임 화면으로 확인.
- 플레이타임은 **내용으로** 늘린다. 처치 수를 늘리거나 이동을 길게 만드는 식의 숫자 늘리기는 보조 수단으로만 쓴다.
- 장 하나가 "완료 기준"(각 장 문서)을 통과해야 다음 장으로 넘어간다.

## 전체 구성 (안)

| 구성 | 분량 | 상태 |
|---|---|---|
| 1장 느티골 — 무기의 길 | 약 25분 | 완료 (`docs/game-design-30min.md`) |
| 2장 잠긴숲과 고대 유적 | 약 30분(측정) | 메인·곁가지 완료 (`docs/chapter2-sunken-forest.md`) |
| 3장 얼어붙은 북쪽 | 약 24분(측정) | 메인·곁가지 구현, 플레이 확인 전 (`docs/chapter3-frozen-north.md`) |
| 4장 ~ 8장 | 장당 60~80분 | 미정 — 3장 끝에 4장(남쪽 불의 산) 고리를 둔다 |
| 반복 콘텐츠 (강화, 현상수배, 던전 재도전 등) | 1~2시간 | 미정 |
| **합계** | **10시간 이상** | |

장 하나의 기본 틀 (2장에서 다듬어 이후 장의 본으로 삼는다):

- 새 거점 마을 1 + 사냥터 2~3 + 던전 1~2층 + 중간 보스 + 최종 보스
- 메인 퀘스트 8~10 + 곁가지 5~8
- 새 몬스터 4~5종, 장비 한 등급, 지역 고유 장치 1~2개
- 다음 장으로 이어지는 이야기 고리

## 장 사이를 잇는 시스템 (언제 만들지)

장이 늘수록 효과가 커지므로 2~3장 사이에 차례로 넣는다. 각각 따로 설계 문서를 쓴다.

| 시스템 | 왜 필요한가 | 시점 (안) |
|---|---|---|
| 장비 강화 | 남는 골드를 쓸 곳. 같은 장비를 오래 쓰게 한다 | 2장 장비 등급과 함께 |
| 빠른 이동 (귀환 표지석 네트워크) | 지역이 늘면 왕복이 지루해진다 | **완료(2026-10-05)** — `waystones.ts`, 맵 오브젝트 `waystone_<id>`, 월드 저장 `discoveredWaystoneIds`. 느티골·물레골·갈대골·신전 외곽 야영지·서리목. 새 장의 거점마다 하나씩 더한다 |
| 현상수배 게시판 | 지나온 지역에 다시 갈 이유. 반복 콘텐츠의 축 | 2장 이후 |
| 세이브 슬롯·장 선택 | 10시간 게임에 필수 | 3장 전 |
| 스킬 확장 | 무기별 스킬이 3개씩이라 10시간을 버티기 어렵다 | 장마다 1~2개 |

## 그림 (가장 큰 제약)

- 지금 몬스터는 4종뿐. 10시간이면 25~30종이 필요하다.
- 사람형 적(해골·좀비·도적·사제 등)은 이미 쓰는 Universal LPC 생성기로 만든다 — 그림체가 확실히 맞는다.
- 동물·괴물형은 LPC 계열 팩에서 장마다 찾는다. 다운로드 전에 출처·라이선스 목록을 사용자에게 보여 주고 승인받는다.
- 모든 새 그림은 CREDITS와 게임 안 크레딧 화면에 들어가야 완료다.

## 측정

- `npx vite-node scripts/estimate-playtime.ts` — 장이 늘면 장별로 나눠 재도록 스크립트를 넓힌다.
- 측정 가정: 읽기 분당 550자, 휘두르기 0.62초 등 (스크립트 맨 위 상수).
- 측정은 추정일 뿐이다. 장이 끝날 때마다 **실제로 한 번 처음부터 플레이**해서 시간을 잰다.
